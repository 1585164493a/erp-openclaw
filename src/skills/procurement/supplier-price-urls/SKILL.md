# 供应商报价网址映射

## 用途

提供「商品名称 + 供应商名称 → 报价页 URL」的映射查询，是外部报价采集的第一步。

| 输入 | 来自 | 输出 |
|---|---|---|
| 商品名、供应商名 | ERP MCP 工具（`product_search` / `supplier_query`） | 报价页 URL |
| 报价页 URL | 本技能的映射表 | 交给 `web-scraper` 抓取 |

## 数据文件

`data/url_mapping.yaml`：

```yaml
mappings:
  - product_name: "澜溪去屑洗发露 清爽控油型"
    supplier: "珠海中福实业股份有限公司"
    product_code: "HFS-400-01"
    url: "http://127.0.0.1/quotes/HFS-400-01-珠海中福实业股份有限公司.html"
```

> ⚠️ **这个文件是生成的，不要手改** —— 它由 `mock_site/generate.py` 从
> `product_supplier` 表（候选报价）生成。要改数据请改库，然后重跑生成脚本。

> ⚠️ **映射表里【没有价格】**。价格必须去页面上抓 —— 这正是本技能存在的意义：
> 库里的报价是历史快照，页面上的才是"最新报价"。

## 使用流程

1. `read_file` 读取 `data/url_mapping.yaml`
2. 用 ERP 工具返回的**商品名 + 供应商名**查找匹配条目
3. 匹配逻辑（两个字段**同时**命中才算）：
   - `product_name` **包含匹配** —— ERP 返回的商品名包含在映射的 `product_name` 中，或反之
   - `supplier` **包含匹配** —— ERP 返回的供应商名包含在映射的 `supplier` 中，或反之
   - 同一商品通常有**多家供应商**的条目，全部收集
4. 把找到的 URL 逐个交给 `web-scraper` 抓取，从页面提取最新报价 + 起订量 + 交期

## 示例

```
ERP 返回: product_name="澜溪去屑洗发露", supplier="珠海中福"
→ 查 url_mapping.yaml
→ 命中: product_name 包含 "澜溪去屑洗发露" + supplier 包含 "珠海中福"
  url="http://127.0.0.1/quotes/HFS-400-01-珠海中福实业股份有限公司.html"
→ 交给 web-scraper 抓取 → 从页面提取：当前报价 17.76 元/瓶、起订 30 瓶、交期 9 天
```

**比价时要注意**：同一商品的多家供应商都要抓，最后按价格 + 交期 + 信用评级综合比较，
不要只看最低价（交期长、评级低的供应商可能反而更贵）。

## 注意事项

- 映射表由生成脚本维护，Agent **只读不写**
- 未找到匹配条目 → 改用 `web_search` 搜索市场价格，**不要编造价格**
- 商品名可能带完整规格描述（品牌、系列、容量），匹配时用**包含关系**而非精确匹配
- 抓取失败（页面不可达）→ 如实说明该供应商报价获取失败，不要用其它供应商的价格顶替
